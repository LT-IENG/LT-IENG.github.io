# 决胜养老院

> TX Hack GameJam 参赛作品 — 养老院模拟经营 + 卡牌说服游戏

## 项目简介

《决胜养老院》是一款养老院管理模拟游戏，玩家扮演院长，通过沙盒建造、员工管理、老人关怀与卡牌说服系统，将一座废弃养老院建设为全国最大的养老社区。

- **类型**：模拟经营 + 文字剧情 + 卡牌战斗
- **平台**：浏览器端（静态 HTML/CSS/JS）
- **版本**：v4.0

## 项目结构
项目地址：https://github.com/LT-IENG/juesheng-yanglaoyuan

```
├── web/               # 游戏源码
│   ├── index.html     # 主页面
│   ├── css/           # 样式
│   └── js/            # 游戏逻辑（data/audio/engine/ui/app）
├── 美术资产/           # 美术资源（61个文件）
│   ├── 人物/          # 角色立绘
│   ├── 卡牌/          # 卡牌插画
│   ├── 背景/          # 场景背景
│   ├── 结局/          # 结局CG
│   └── sprite_sheet/  # 精灵图
├── 音乐资产/           # 音乐资源（4个文件）
│   ├── 背景音乐_主界面.mp3
│   ├── 背景音乐_剧情.mp3
│   ├── 背景音乐_卡牌战斗.mp3
│   └── 音效_按钮.mp3
└── *.md               # 设计文档（GDD、剧情、数值、经济系统等）
```
