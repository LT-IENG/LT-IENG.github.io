# 个人网站重设计 — 设计方案 v3

> 目标：取代 Hexo + Butterfly，打造一个美观、现代、GitHub Pages 友好的静态个人博客。

---

## 一、现状分析

| 项目 | 现状 |
|------|------|
| **框架** | Hexo 8.x + Butterfly 5.x 主题 |
| **内容** | 6 篇博文，3 个分类（AI、博客技巧、经济学） |

## 二、设计参考分析

### 参考站 A：hellodani.co（Daniella Marynova）

- **色调**：暖奶油色 + 灰粉 — 温暖柔和，避免纯白底色的冷淡感
- **字体**：干净极简，排版对比突出 CTA
- **动效**：慢速、克制的微交互；bento 网格的 spring hover；循环视频嵌入
- **布局**：Bento 网格展示项目；"Garden"页无上下文纯视觉浏览
- **亮点**：花卉插画作为结构性视觉元素；动效节奏精准

### 参考站 B：nivedhanirmal.com（Nivedha Nirmal）

- **色调**：深色/中性调
- **字体**：字体驱动品牌识别 — 无个人照片，纯靠排版和颜色传达个性
- **动效**：极简克制的微交互；About 页有互动卡片 + 旋转 CD 动画
- **布局**：全幅视觉案例展示；留白充足让作品"呼吸"
- **亮点**：排版 + 色彩 + 动效三位一体传达身份

### 共同设计 DNA

1. **去模板化** — 不像 AI 生成的通用网站
2. **动效克制** — 慢、有意、有目的，不装饰
3. **强排版** — 字体本身就是设计元素
4. **呼吸感** — 充足留白，内容不拥挤
5. **个性表达** — 不依赖照片，靠设计语言传达个性

## 三、技术选型

### 最终选择：Astro

| 维度 | Astro | Hexo | Hugo |
|------|-------|------|------|
| 静态输出 | ✅ SSG 默认 | ✅ | ✅ |
| 组件化 | ✅ React/Vue/Svelte/Alpine | ❌ EJS/Pug | ❌ partials |
| 动效支持 | ✅ 任意 JS 库 | ⚠️ 受限 | ⚠️ 受限 |
| Content Collections | ✅ 类型安全 | ❌ | ❌ |
| GitHub Pages | ✅ | ✅ | ✅ |

**选 Astro 的核心原因**：
- 纯静态输出 → GitHub Pages 完美适配，零服务器成本，国内 ICP 备案无障碍
- Markdown 写博客习惯完全保留（`src/content/blog/`）
- 首页可自由设计：Canvas 粒子背景、精选滑动卡片、板块概览 — 不受主题限制
- 默认 0 JS，仅在需要交互处加载
- Astro 5.x 原生 View Transitions，页面切换丝滑

### 背景方案：Canvas 粒子网络

| 维度 | Canvas 粒子网络 | Three.js 3D |
|------|----------------|-------------|
| 视觉效果 | ⭐⭐⭐⭐ 优雅克制 | ⭐⭐⭐⭐⭐ 沉浸震撼 |
| 性能 | ⭐⭐⭐⭐⭐ 60fps | ⭐⭐⭐ 需优化 |
| 包体积 | 0 KB（原生 API） | ~150 KB（three.js） |
| 移动端 | ⭐⭐⭐⭐⭐ 流畅 | ⭐⭐⭐ 需降级 |
| 博客适配 | ⭐⭐⭐⭐⭐ 不抢内容 | ⭐⭐ 喧宾夺主 |
| 作品集适配 | ⭐⭐⭐ 够用 | ⭐⭐⭐⭐⭐ 印象深刻 |

**选择 Canvas** — 优雅、轻量、不抢内容、移动端友好。

## 四、设计系统

> 🔧 配色和字体将在实现阶段通过 `design-taste-frontend` / `impeccable` / `high-end-visual-design` 
> 等 skill 进行精细化调整。以下为初始方向。

### 4.1 风格定位

**关键词**：温暖 × 科技感 × 编辑感

- 温暖底色 + 克制的科技元素（粒子/几何/线条）+ 编辑级排版
- 参考 hellodani 的温度 + nivedha 的字体驱动 + LT-IENG 的技术博客属性
- 不炫技，让内容说话

### 4.2 色彩方向（参考两站融合）

```
hellodani 方向:  暖奶油 + 灰粉 + 植物的有机感
nivedha 方向:   深中性 + 字体对比 + 冷峻克制
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LT-IENG 方向（融合）:

主背景:    暖白/奶油系
文字:      深灰/蓝黑
强调:      暖金/铜色
点缀:      低饱和色块（四板块各有主题色）
代码区:    暖灰底
卡片:      纯白 + 微阴影
```

> 最终配色将在实现时通过设计 skill 精调

### 4.3 字体方向

```
英文标题: serif 类（如 Playfair Display）
中文标题: 思源宋体 / 其他衬线
英文正文: Inter
中文正文: 霞鹜文楷 / 其他优质中文体
代码字体: JetBrains Mono
```

### 4.4 动效策略

| 位置 | 动效 | 实现 | 备注 |
|------|------|------|------|
| Hero 背景 | 粒子浮游 + 连线 + 鼠标吸引 | Canvas API | 持续循环 |
| 精选卡片 | 横向自动滚动，hover **减速**（非暂停） | CSS scroll-snap + JS | 关键交互 |
| 板块卡片 | 滚动淡入 + 交错出现 | GSAP / IntersectionObserver | 0.6s |
| 卡片 hover | 上浮 + 阴影加深 + 板块色微光 | CSS transition | 0.25s |
| 链接 hover | 下划线从中间展开 | CSS ::after | 0.3s |
| 页面切换 | 淡入淡出 | View Transitions API | 0.3s |
| 简历区 | 滚动驱动的时间线/进度动画 | GSAP ScrollTrigger | 可选 |

### 5.2 精选滑动区（Hero 下半部分）交互

**这是页面最重要的交互亮点：**

- **位置**：Hero 全屏的下半部，叠加在粒子背景之上
- **自动滚动**：卡片从左向右匀速自动滑动
- **Hover 减速**：鼠标悬停时滚动速度降至 20%（不是完全停止，保持"呼吸感"）
- **手动拖拽**：支持鼠标拖拽 + 触摸滑动
- **卡片对齐**：CSS scroll-snap-type: x mandatory
- **导航指示**：底部小圆点，当前高亮
- **循环**：滚动到末尾后无缝循环

### 5.3 板块页 (`/section/[name]`)

点击首页板块卡片 → 进入该板块的文章列表：
- 板块标题 + 描述
- 文章卡片列表
- 分页

### 5.4 博客总列表 (`/blog`)

- 所有文章，带搜索 + 板块筛选
- 文章卡片（封面图 + 标题 + 摘要 + 日期 + 板块标签）

### 5.5 文章详情 (`/blog/[slug]`)

- 宽栏排版（max-width ~720px）
- 代码高亮：Shiki（暖色主题）
- 数学公式：KaTeX
- 底部：CC 版权声明 + 上一篇/下一篇导航
- ❌ 无评论区

### 5.6 关于页 (`/about`)

- 个人简介、技能标签、社交链接
- 独立页面，首页简历区为简短版本

### 5.7 时间轴 (`/archives`)

- 保留 Butterfly 的时间轴页面
- 按年份分组，倒序展示所有文章
- 简洁时间线布局

### 5.8 搜索

- 全站搜索，使用 Pagefind
- 构建时生成静态索引，零服务器依赖
- 支持中文分词，搜索结果高亮
